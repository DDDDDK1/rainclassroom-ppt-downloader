# 长江雨课堂 PPT 下载器

一个用于 [长江雨课堂](https://changjiang.yuketang.cn) 的油猴（Tampermonkey）用户脚本，帮你便捷地下载课程中的 PPT 课件，具备**增量检测**能力：首次扫描记录全部课程及课件，之后每次扫描只呈现新增内容，避免重复下载。

> 本项目仅供个人学习使用，请遵守平台条款与课件版权要求（详见下文合规声明）。

## 功能特性

- **增量扫描**：点击悬浮按钮即可扫描课程列表；已扫描过的课件自动记录在本地缓存（GM 存储），再次扫描只列出新增课件，无新增时提示「无新增课件」。
- **直链下载**：对带直链的课件（PDF / PPTX），通过浏览器原生下载逐个保存到本地，下载间隔自动控制，降低风控风险。
- **图片流课件 → 打印导出 PDF**：长江雨课堂的课堂 PPT 多为分片图片流（无原始文件），脚本通过雨课堂自带的打印功能将整份 PPT 导出为 PDF：
  - **CDP 全自动**：若以 `--remote-debugging-port=9222` 启动 Chrome，可调用 DevTools 协议自动生成 PDF 文件并保存；
  - **半自动回退**：未启用调试端口时，自动打开打印页并调用系统打印框，手动「另存为 PDF」即可。
- **中文界面**：右下角悬浮按钮 + 模态面板（全选 / 下载选中 / 清空缓存 / 关闭），无外部依赖。
- **容错加固**：接口请求带重试与退避；单门课失败自动跳过并提示；登录失效（401）时明确提示；缓存损坏自动自愈。

## 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 等浏览器均支持）。
2. 在浏览器扩展栏点击 Tampermonkey 图标，选择「管理面板」（Dashboard）。
3. 点击「＋」（新建脚本）按钮，删除编辑器中的默认内容，粘贴本脚本的全部代码。
4. 保存（Ctrl+S / Cmd+S），脚本即自动启用。

> 也可以直接安装本仓库 `rainclassroom-ppt-downloader.user.js` 文件（通过 Tampermonkey 的「从文件导入」或将文件拖入扩展页面）。

## 使用步骤

1. 在浏览器中**登录**长江雨课堂（`changjiang.yuketang.cn`），确保能正常看到「我听的课」列表。
2. 打开课程主页 `https://changjiang.yuketang.cn/v2/web/index`，页面右下角会出现「📄 雨课堂PPT下载」悬浮按钮。
3. 点击按钮开始扫描（首次扫描课程较多时需等待约 1 分钟，按钮会显示「扫描中…」）。
4. 扫描完成后，面板列出**新增课件**：勾选要下载的课件，点击「下载选中」即可逐个下载 / 导出 PDF。
5. 再次点击按钮扫描，无新增时会提示「无新增课件」；如需重新全量检测，可点击面板中的「清空缓存」。

### CDP 全自动导出（可选）

若希望图片流课件自动生成 PDF 而无需手动操作打印框，请用以下方式启动 Chrome 后访问雨课堂：

```
chrome.exe --remote-debugging-port=9222
```

脚本会自动探测 `http://localhost:9222`，走 CDP 全自动路径导出 PDF。未启用时自动回退到半自动打印框（需手动「另存为 PDF」）。

## 工作原理

脚本运行在页面上下文中，通过同域接口（课程列表 / 课件列表 / 分片图片）获取数据：

- 课程列表接口一次性返回全部课程（无分页）；
- 增量判定以 `课程ID + 教室ID + 课件ID` 为唯一键，与课件名无关（防重名误判）；
- 数据仅存本地（GM 存储），不上传任何信息。

详见 `docs/apis.md`（接口契约）。

## 已知限制

- **图片流课件无法下载源文件**：长江雨课堂的课堂 PPT 只有分片图片、无原始 PPT/PDF 文件，脚本通过打印功能导出 PDF，输出质量与原课件一致但无法还原为可编辑的 PPT。
- **CDP 全自动需调试端口**：未以 `--remote-debugging-port=9222` 启动 Chrome 时，图片流课件走半自动路径，会弹出系统打印框，需手动「另存为 PDF」；若浏览器拦截了弹窗，请在地址栏允许弹窗后重试。
- **接口变更风险**：脚本依赖长江雨课堂的内部接口，若平台调整接口地址 / 字段 / 鉴权方式，功能可能失效。接口地址集中在脚本顶部 `API` 常量中，便于单点修改；连续失败时脚本会提示「接口可能已变更」。
- **首次扫描较慢**：逐门课串行扫描（含请求间隔），课程多时首次扫描约需 1 分钟。
