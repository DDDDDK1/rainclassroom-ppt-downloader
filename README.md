# 长江雨课堂 PPT 下载器

一个用于 [长江雨课堂](https://changjiang.yuketang.cn) 的油猴（Tampermonkey）用户脚本，帮你便捷地下载课程中的 PPT 课件，具备**增量检测**能力：首次扫描记录全部课程及课件，之后每次扫描只呈现新增内容，避免重复下载。

> 本项目仅供个人学习使用，请遵守平台条款与课件版权要求（详见下文合规声明）。

## 功能特性

- **二级浏览窗口**：点击悬浮按钮打开浏览窗口，第一级列出全部已扫描课程（可勾选），点击课程下钻第二级查看该课课件；勾选即整行高亮，可「下载选中」批量导出。
- **增量扫描**：窗口内点击「扫描」按钮即可扫描课程列表；已扫描过的课件自动记录在本地缓存（GM 存储），再次扫描只列出新增课件并加「新」徽标，无新增时提示「无新增课件」。
- **直链下载**：对带直链的课件（PDF / PPTX），通过浏览器原生下载逐个保存到本地，下载间隔自动控制，降低风控风险。当前扫描器仅采集课堂 PPT 图片流课件，直链下载分支暂不可达，图片流导出走前端合成 PDF（见下）。
- **图片流课件 → 前端合成 PDF**：长江雨课堂的课堂 PPT 多为分片图片流（无原始文件），脚本逐页拉取完整图片字节，在前端合成单个 PDF 文件并自动下载：
  - 逐页并发拉取、逐页等待完整加载（无固定计时赌渲染），不会出现空白页；
  - 不依赖 Chrome 调试端口，无需手动「另存为」，无弹窗。
- **中文界面**：右下角悬浮按钮 + 模态面板（全选 / 下载选中 / 清空缓存 / 关闭），无外部依赖。
- **容错加固**：接口请求带重试与退避；单门课失败自动跳过并提示；登录失效（401）时明确提示；缓存损坏自动自愈。

## 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 等浏览器均支持）。
2. 在浏览器扩展栏点击 Tampermonkey 图标，选择「管理面板」（Dashboard）。
3. 点击「＋」（新建脚本）按钮，删除编辑器中的默认内容，粘贴本脚本的全部代码。
4. 保存（Ctrl+S / Cmd+S），脚本即自动启用。

> **推荐**：通过上方「新建脚本 → 粘贴」方式安装。Tampermonkey 编辑器以 UTF-8 保存脚本，中文界面不会乱码。
>
> **若中文界面乱码**：在中文版 Windows 上，直接双击本地 `rainclassroom-ppt-downloader.user.js`、或经浏览器以 `file://` 打开该文件安装时，Chrome 可能按 GBK 解码无编码声明的文本，导致按钮等中文显示为乱码（如「长江」变成「闀挎睙」）。此时请删除脚本，改用「新建脚本 → 粘贴」重新安装。
>
> 发布到 GitHub 后，`@updateURL` 指向 raw.githubusercontent.com（响应自带 `charset=utf-8`），可放心通过该链接直接安装与更新。

## 使用步骤

1. 在浏览器中**登录**长江雨课堂（`changjiang.yuketang.cn`），确保能正常看到「我听的课」列表。
2. 打开课程主页 `https://changjiang.yuketang.cn/v2/web/index`，页面右下角会出现「📄 雨课堂PPT下载」悬浮按钮。
3. 点击按钮打开「已扫描课件」窗口。首次使用为空，点击「开始扫描」完成全量扫描（课程较多时约需 1 分钟，按钮会显示「扫描中…」）。
4. 窗口第一级列出全部课程：勾选课程可整行选中，点击课程名下钻查看该课课件。
5. 在课件列表中勾选要下载的课件（整行高亮），点击「下载选中」逐个下载 / 导出 PDF；「清空缓存」可重置本地记录。

## 工作原理

脚本运行在页面上下文中，通过同域接口（课程列表 / 课件列表 / 分片图片）获取数据：

- 课程列表接口一次性返回全部课程（无分页）；
- 增量判定以 `课程ID + 教室ID + 课件ID` 为唯一键，与课件名无关（防重名误判）；
- 数据仅存本地（GM 存储），不上传任何信息。

详见 `docs/apis.md`（接口契约）。

## 已知限制

- **图片流课件无法下载源文件**：长江雨课堂的课堂 PPT 只有分片图片、无原始 PPT/PDF 文件，脚本将各页图片前端合成为单个 PDF（每页一张原图，页尺寸统一），无法还原为可编辑的 PPT。
- **接口变更风险**：脚本依赖长江雨课堂的内部接口，若平台调整接口地址 / 字段 / 鉴权方式，功能可能失效。接口地址集中在脚本顶部 `API` 常量中，便于单点修改；连续失败时脚本会提示「接口可能已变更」。
- **首次扫描较慢**：逐门课串行扫描（含请求间隔），课程多时首次扫描约需 1 分钟。
- **第一级批量下载无逐文件进度**：勾选整门课下载时，仅显示窗口内进度行（第 N/总数 个），不逐行标记状态；课件级勾选才逐行显示 ✓/失败。
