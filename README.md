# 长江雨课堂 PPT 下载器

一个用于 [长江雨课堂](https://changjiang.yuketang.cn) 的油猴（Tampermonkey）用户脚本：帮你在浏览器里把课堂 PPT 课件**导出为 PDF**，并具备**增量检测**——首次扫描记录全部课件，之后只提示新增内容，避免重复下载。

> ⚠️ **重要声明（请先阅读）**
>
> - 本工具**非雨课堂官方产品**，仅供个人学习使用；使用过程中存在触发账号风控、功能受限的可能性。
> - 课件**版权归授课教师及学校所有**，下载内容仅供个人学习备份，**禁止二次分发与传播**。
> - 脚本依赖雨课堂**非公开接口**，平台更新可能导致失效，**不保证永久可用**。
> - 脚本数据仅保存在本机浏览器（GM 存储），**不会上传任何服务器**。

## ✨ 功能特性

**可以做的：**

- **一键导出 PDF**：课堂 PPT 多为分片图片流（没有原始文件），脚本逐页拉取完整图片字节，在浏览器内**前端合成单个 PDF** 并自动下载——无需手动「另存为」，不会出现空白页。
- **增量检测**：首次扫描记录全部课程/课件，之后只列出新增内容并加「新」徽标；无新增时提示「无新增课件」。
- **一键选中**：浏览窗口内「选中新增」精确到**新增文件**——一级一键打开本次全部新增课件列表（按课程分组、默认全勾），「下载选中」只下载这些新增件，**不会连带已下载的旧课件**；二级可勾某课程全部新增文件。无需逐个手动勾选。
- **扫描历史**：每次**有新增**的扫描自动留档（时间 + 该次新增文件快照，保留最近 100 条）——一级点「历史」按次回看，可任意重选某一次扫描的内容下载，无需重新扫描；「清空缓存」会一并清空历史。
- **设置版块**：悬浮浏览窗口右上角 ⚙ 进入设置——自定义保存目录（跨会话记住）、按课程自动分类下载、清空缓存
- **无文件提示**：无课件的课堂下载时行内提示「此课堂无文件」

**不能做的：**

- ⚠️ **绝大多数课件只能导出 PDF 图片版，拿不到原始 PPT/PPTX 源文件。** 雨课堂课上 PPT 本质是分片图片，没有可下载的源文件；脚本只能把它们合成为 PDF 图片版（每页一张原图），无法还原为可编辑 PPT。仅极少数带直链的课件可直接下载源 PDF/PPTX。

## 📦 安装教程

### 第 1 步：安装 Tampermonkey

- **Chrome / Edge**：在 [Chrome 应用商店](https://chrome.google.com/webstore/search/Tampermonkey) 或 [Edge 加载项](https://microsoftedge.microsoft.com/addons/) 搜索安装 **Tampermonkey**。
- **Firefox**：在 [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tampermonkey/) 安装。

安装后浏览器扩展栏会出现 Tampermonkey 图标。

### 第 2 步：安装本脚本

**✅ 方式一：Greasy Fork 一键安装（推荐）**

1. 打开脚本发布页：<https://greasyfork.org/zh-CN/scripts/589891>
2. 点击页面右侧绿色的 **「安装此脚本」** 按钮。
3. Tampermonkey 弹出安装确认页，点击 **「安装」** 即可。

**方式二：手动粘贴安装（备选）**

1. 点击浏览器扩展栏 Tampermonkey 图标 → 选择「管理面板」（Dashboard）。
2. 点击「＋」（新建脚本），删除编辑器中的默认内容。
3. 粘贴本脚本的全部代码（从本仓库 `rainclassroom-ppt-downloader.user.js` 复制，或从 Greasy Fork 脚本页「源代码」标签复制）。
4. 保存（Ctrl+S / Cmd+S），脚本自动启用。


## 🚀 使用教程

1. **登录** 长江雨课堂（`changjiang.yuketang.cn`），确保能正常看到「我听的课」列表。
2. 打开课程主页，页面右下角出现「📄 雨课堂PPT下载」悬浮按钮。
3. 点击按钮打开「已扫描课件」窗口。首次使用为空，点击「开始扫描」完成全量扫描（课程较多时约需 1 分钟，按钮会显示「扫描中…」）。
4. 窗口第一级列出全部课程：勾选课程可整行选中，或点击课程行（非勾选框）在其下**行内展开**该课课件——可多门同时展开，展开的文件行（类型徽标 + 名称 +「新」）可直接勾选；扫描有新增时点「选中新增」列出本次全部新增课件，点顶栏「历史」回看历次新增记录。
5. 勾选要导出的内容（整行勾课程=下载整门；展开内勾文件=单文件下载），点「下载选中」即可，浏览器自动下载 / 导出 PDF；如需清空本地记录，清空缓存入口已移至 ⚙ 设置面板（会一并清空扫描历史）。
6. 点击窗口右上角 ⚙ 打开设置：可「选择目录」自定义保存位置（Chrome/Edge）；勾选「按课程自动创建文件夹」后下载自动按 `课程名（班级名）` 归档；
## ⚠️ 已知限制

- **拿不到可编辑 PPT**：绝大多数课件为分片图片，脚本只能前端合成为 PDF 图片版，无法还原成可编辑 PPTX。
- **接口变更风险**：脚本依赖雨课堂内部接口，平台调整接口地址 / 字段 / 鉴权即可能失效；连续失败时脚本会提示「接口可能已变更」。
- **首次扫描较慢**：逐门课串行扫描（含请求间隔），课程多时首次约需 1 分钟。
- **请勿高频大量下载**：短时间大量请求可能触发账号风控，请合理使用（脚本已内置请求间隔）。
- **自定义保存目录与分类下载**：依赖 Chrome/Edge 的 File System Access API，Firefox 不支持（自动回退浏览器默认下载目录）。

## ❓ FAQ 常见问题

- **扫描不出课件？** 确认已登录雨课堂且能正常看到「我听的课」；刷新课程页后重新打开窗口再试。
- **按钮 / 界面乱码？** 用「Greasy Fork 一键安装」重新安装即可；手动粘贴时请确认 Tampermonkey 编辑器按 UTF-8 保存。
- **导出后不是可编辑 PPT 怎么办？** 这是正常限制——课件源就是分片图片，只能导出 PDF 图片版，无法得到可编辑 PPTX。
- **怎么清除脚本本地缓存？** 打开浏览窗口右上角 ⚙ 设置，点击「清空缓存」即可重置。
- **脚本突然失效了？** 雨课堂接口更新属正常现象，可到 Greasy Fork 页面或本仓库查看是否有新版本。
